01 · Academic Research (2022.06)

「CNN 분류 프로그램을 이용한 쓰레기 분류 장치에 대한 연구」

A Study on Garbage Sorting Device Using CNN Classification Program · 한국정보과학회 『2022 한국컴퓨터종합학술대회 논문집 (KCC 2022)』 pp. 2,269–2,270

DBpia 공식 논문 페이지 열기 (NODE11113931) ↗
논문 초록 (Abstract) 및 연구 배경

“AI에서 사용되는 CNN(Convolution Neural Network)은 데이터의 특징을 추출하여 특징의 패턴을 파악하는 구조로 되어있는 모델이다. 이러한 모델은 이미지 분류, 분석 등에서 영상 이미지 처리 부분쪽에서 많이 사용되고 있다. 본 논문에서는 이러한 모듈을 이용해서 제어부, 클라이언트, API, AI 머신러닝으로 구성된 쓰레기 분류 장치를 연구하였다. 또한 연구된 쓰레기 분류 장치를 구현하고 동작 테스트를 통해 이미지 분류를 통한 쓰레기 분류가 가능한 장치를 개발하였다.”

임미르 (함덕고등학교, 제1저자)
한승의 (제주대학교, 공동저자)

4대 핵심 시스템 아키텍처 및 하드웨어 제어 원리

  • • 클라이언트 (Android App): 사용자가 배출할 재활용 쓰레기(플라스틱 페트병, 종이, 유리, 캔 등)를 카메라로 촬영하고 API 서버로 이미지를 전송하여 분류 코드를 요청한 뒤, 블루투스(Bluetooth) 통신으로 제어부에 도어 개방 명령을 전달합니다.
  • • API 서버 & AI 분류 모델 (TensorFlow/Keras): 512×384×3 해상도 이미지를 입력받아 4단계 Conv2D + MaxPooling2D 계층을 거쳐 6개 클래스(캔, 유리, 종이, 플라스틱, 박스, 비닐/일반)로 분류하고 결과 코드(예: {"plastic": 1})를 반환합니다.
  • • 아두이노 제어부 (Arduino & 3-Channel Servo Motors): 블루투스 모듈(BT.read())로 수신한 분류 코드에 따라 1번(캔/금속), 2번(유리), 3번(플라스틱) 서보모터를 90도 회전시켜 해당 분리수거함 도어를 자동으로 개방하고 2.5초 뒤 닫습니다.

2022 EcoCycling 사업계획서 및 엔지니어링 설계 핵심 요약

1. 제주 관광지 쓰레기 문제 & 공공데이터 분석
우도·성산일출봉·함덕해수욕장·삼양해수욕장 등 관광객 밀집 구역에서 매년 일회용 컵 약 6,300만 개가 배출되며 제주도민 1인당 일평균 생활폐기물 배출량이 1.8kg(전국 평균 1.1kg 대비 1위)에 달하는 문제를 해결하기 위해, 제주 관광객 이동 동선 클러스터 데이터를 기반으로 최적의 AI 수거함 거점을 설계했습니다.
2. 시제품 H/W 및 24시간 3D 프린팅 팜
• AI 분리수거함 시제품: NVIDIA Jetson Nano 컴퓨팅 보드, LV5300 QR 스캐너, YR-030 인식 카메라, DF2020 프로파일 프레임
• 3D 프린팅 팜 설비: NPCP-150 플라스틱 분쇄기(크러셔)로 세척·파쇄된 HDPE/LDPE를 SJ25 압출기로 필라멘트화하여 Ender-5 Plus 3D 프린터 팜에서 기념품·교육용 과학 키트 생산.
03 · Platform Evolution (2024 제3회 전국 장애·비장애 대학생 창업경진대회)

ONECYCLE: 유니버설 AI 분리수거 & 초분광 펠릿·필라멘트 순환 플랫폼

2024년 제3회 전국 장애·비장애 대학생 창업경진대회에서 Team None은 기존 EcoCycling을 ONECYCLE(원사이클)로 고도화하여, 누구나 제약 없이 한 번에 여러 쓰레기를 투입할 수 있는 배리어프리(Barrier-Free) 키오스크 UX와 초분광 카메라(Hyperspectral Camera) 기반 2차 정밀 분류·펠릿(Pellet) 제조 공정을 선보였습니다.

EVOLUTION 01 · UNIVERSAL ACCESSIBILITY

다중 쓰레기 동시 투입 & 배리어프리 키오스크

한 번에 한 개씩 단일 품목(페트·캔)만 넣어야 했던 기존 수거함(슈퍼빈 등)과 달리, 묶음·다중 쓰레기를 동시에 투입해도 AI가 자동 선별합니다. NFC/QR 태깅 시 자동 도어 개폐(투입구가 열립니다)와 직관적인 3단계 상태 UI로 장애·비장애인 모두 편리하게 이용할 수 있습니다.

EVOLUTION 02 · HYPERSPECTRAL SORTING

초분광 카메라 기반 10종+ 폐플라스틱 정밀 분류

인간의 가시광선 영역을 넘어선 파장을 분석하는 초분광 카메라(Hyperspectral Camera)를 2차 공정에 도입하여 PLA, ABS, PVC, PP, PET 등 10종 이상의 플라스틱 재질을 정확히 선별·파쇄하고 고순도 플라스틱 펠릿(Pellet)과 3D 프린터 필라멘트로 가공합니다.

EVOLUTION 03 · TOURISM & ESG MARKET

관광 상권 플로깅(Plogging) 만보기 & B2B·B2G 확장

부산 해운대·제주 함덕·인천 차이나타운·대학가 등 유동 인구가 많은 관광 상권과 연계해 걸음 수(만보기)와 배출량에 따라 지역 가맹점 상품권(5,000원/10,000원권)을 지급하며, 국내 201조 원·글로벌 737억 달러 규모(2026 전망) 재활용 시장을 타겟팅합니다.

ONECYCLE AI 스마트 쓰레기통 & 키오스크 인터페이스

3채널 분리수거 하드웨어 외관 설계 및 캔(400pts)·페트병(300pts)·유리병(240pts)·일반쓰레기(5pts) 실시간 합산(945pts) 화면.

ONECYCLE 모바일 앱 (관광지·맛집 탐색 / AI 쓰레기통 지도 / 포인트 교환)

QR코드 스캔, 내 주변 ONECYCLE 가맹점 및 쓰레기 수거함 탐색, 지역 상권 모바일 이용권 교환 UI.

초분광 카메라(Hyperspectral) 기반 폐플라스틱 펠릿 · 필라멘트 공정

활용 오픈소스 소프트웨어 및 데이터셋 명세

ONECYCLE (EcoCycling) 연구 논문, 하드웨어 제어부, 모바일 웹 애플리케이션, 스마트 키오스크 및 백엔드 서버 구현에 활용된 모든 오픈소스 라이브러리·폰트·데이터셋 내역입니다.

1. AI 비전 연구 및 하드웨어 제어 (2022–2024)
  • • TensorFlow & Keras (Apache-2.0 License): 4-Stage Conv2D 쓰레기 이미지 분류 딥러닝 모델 학습 및 추론
  • • Python & NumPy / Pillow (PSF / BSD-3-Clause): 이미지 전처리(512×384 리사이징) 및 추론 API 서버
  • • Kaggle Garbage Classification Dataset (CCHANG, 2018): 6종 재활용 쓰레기 2,527장 학습/테스트 데이터셋
  • • Arduino Servo & SoftwareSerial Library (LGPL-2.1+): 블루투스(HC-06) 시리얼 통신 및 3채널 서보모터 도어 개폐 제어
2. 프론트엔드 웹 앱 & 디자인 시스템
  • • Tailwind CSS (MIT License): 유틸리티 기반 반응형 스타일링 및 소개/홍보관 레이아웃 시스템
  • • Pretendard Font (SIL Open Font License 1.1, by Kil Hyung-jin): 한글·영문 UI 기본 본문 타이포그래피
  • • Archivo Black & Ubuntu Fonts (SIL OFL 1.1 / Ubuntu Font License, Google Fonts): ONECYCLE 브랜드 워드마크 및 숫자 디스플레이 폰트
  • • HTML5 MediaDevices / Canvas / Touch Events API (W3C Web Standards): 실시간 QR 카메라 스캐너 및 터치 스와이프 캐러셀
3. 백엔드 API · IoT 에이전트 & 클라우드
  • • Go (Golang 1.22 Standard Library) (BSD-3-Clause): 백엔드 코어 서버 및 IoT 키오스크 에이전트 런타임
  • • GoFiber (github.com/gofiber/fiber/v2) (MIT License): 고성능 RESTful API 라우팅 및 미들웨어
  • • Gorilla WebSocket / Fasthttp WebSocket (BSD-2-Clause): 키오스크-모바일 실시간 상태 동기화
  • • golang-jwt/jwt (MIT License): OAuth 2.0 및 사용자 세션 JWT 토큰 서명·검증
